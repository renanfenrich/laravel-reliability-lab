# ADR 004 — dedicated single-node kind

kind owns only laravel-reliability-lab cluster and node. Terraform owns lab namespace, Secret, services, storage objects, RBAC and Deployments. Commands always use repository kubeconfig and explicit kind-laravel-reliability-lab context; never switch user's default context. kubectl 1.34.0 is downloaded locally and SHA256-verified because host kubectl 1.36.2 exceeds supported skew for Kubernetes 1.34.

PostgreSQL uses a static Retain PV/PVC backed by a host directory mounted into kind. Cluster removal preserves .runtime/postgres and Compose volumes by default; Compose and Kubernetes databases are independent. Do not copy one live data directory to the other. No HA, backup, disaster recovery, real storage performance or cloud experience is established. Observability data uses emptyDir and is lost on cluster teardown; 30-day retention setting is an intended query horizon, not evidence of retained history.

ClusterIP services and loopback port-forwards limit host exposure. No ingress/public endpoint. App containers run UID1000 with dropped capabilities, no escalation, bounded resources, readonly root plus writable emptyDirs. PostgreSQL/Redis official images retain entrypoint privileges needed to initialize their local volumes; no privileged containers. kind itself is necessarily a privileged Docker node (dedicated local runtime), not a restricted production cluster. kindnet does not enforce NetworkPolicy: no network-isolation claim. RBAC limits Alloy logs to lab namespace; Prometheus receives node/metrics access only for lab node resource scraping. Application development uses PHP CLI server with multiple processes; this is explicitly a lab runtime, not a production web server.

The PV advertises 5Gi but hostPath has no enforced filesystem quota; doctor checks free host disk and measured usage is reported separately. Local volumes are not cloud block devices. API port-forward targets one replica, not a load balancer. Source/checksum rollouts and PVC storageClass `lab-static` avoid empty-field/provider defaults; preexisting operational restart annotations are computed fields, not deployment ownership. Terraform state is sensitive and local-only.
