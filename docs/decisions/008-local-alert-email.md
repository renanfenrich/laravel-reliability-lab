# Local SMTP notification delivery

Use pinned prom/alertmanager:v0.34.1 and axllent/mailpit:v1.31.5, verified against official releases: https://prometheus.io/download/ and https://github.com/axllent/mailpit/releases/tag/v1.31.5 . Both deployments and configuration are Terraform-owned. Nonroot, read-only root, capabilities dropped; writable emptyDir state. Mailpit UI auth file comes from the existing local Secret with lab/LAB_TOKEN. Recipient regex only admits alerts@lab.test; no relay/forwarding enabled. No personal recipient or external message is required. Config reference: https://prometheus.io/docs/alerting/latest/configuration/ ; Mailpit runtime options: https://mailpit.axllent.org/docs/configuration/runtime-options/ .

Prometheus forwards all firing alerts. Alertmanager groups by alertname/severity/mode, sends after 5s, groups updates10s, repeats1h, sends resolved. Every message identifies status/severity/alert/mode, summary and runbook. No inhibition hides slow-window alerts during this lab validation. Delivery is local SMTP only, no TLS claim for internal transport. Only authenticated mailbox UI may be forwarded to trusted LAN; SMTP/Alertmanager remain ClusterIP.

Keep intended SLO thresholds unchanged. Complete positive tests for all 12 burn alerts and three long-window SLI families, plus infra collector outage/recovery. Notification fixtures inject each configured alert into Alertmanager with explicit notification-fixture mode; this verifies routing and firing/resolved delivery, not actual SLO data. Live bounded failures validate three Prometheus alert conditions and their local-email recovery; normal-traffic data is not overwritten or fabricated.

Mailpit state and Alertmanager dedup/silence state are ephemeral like existing observability. Export received messages to repository evidence; no deletes/reset during tests. Pod/cluster recreation loses mailbox history, and sender may resend after dedup state loss. Repeat interval is not an external delivery guarantee. A subsequent goal may add persistence if needed.
