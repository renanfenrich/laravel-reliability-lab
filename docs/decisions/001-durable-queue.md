# ADR 001 — committed reports are the outbox
Accepted: PostgreSQL report row is authoritative. Unique idempotency key + normalized payload hash rejects conflicting replays. Return 202 only after commit. Redis publication occurs afterward; dispatch failure does not undo acceptance. A 5-second reservation bounds duplicate publication; scheduler re-dispatches pending rows after reservation expiry, including crash-before-publish and Redis loss. Atomic locked claim moves pending -> processing, increments one durable attempt and writes a UUID fencing token with 15-second lease. Network timeout 5s < worker timeout 10s < lease 15s < Redis retry_after 20s. Completion updates only the current token; terminal state is immutable. Retries return to pending with 2s/4s backoff; the third failed or interrupted attempt becomes failed. Reconciliation runs every 5s. Three attempts, including interruptions, bound total execution. No exactly-once external side effect claim: simulator is pure and result checksum deterministic. A real external mutating service would require its own idempotency contract.

Single result column prevents duplicate result records. No distributed DB/Redis transaction. Recovery assumes PostgreSQL and scheduler recover; failed reports remain queryable. Queue loss is survivable; database loss is not. Local PostgreSQL is single-node, no backup/HA validation.

Sources: [Laravel queues](https://laravel.com/docs/13.x/queues), especially timeout/retry_after and after-commit semantics. Test suite uses committed migrations, not a wrapping test transaction, to exercise post-commit queue failures.
