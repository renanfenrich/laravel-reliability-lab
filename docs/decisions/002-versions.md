# ADR 002 — pinned compatible versions
Laravel 13.34.0 (exact) + PHP 8.4.26 CLI Bookworm, Composer 2.8.12, Predis 3.2.0 and PHPUnit 12.5.12. composer.lock locks transitive dependencies; PHP platform 8.4.26. Laravel 13 supports PHP 8.3–8.5 and receives security fixes to March 2028; PHP 8.4 remains supported. PHP 8.4.13 was attempted but DOM failed to compile (selectors header missing); replaced with 8.4.26 and retained failed-check description. Apt packages inside the image follow Bookworm security repositories; image build is not a byte-identical OS-package lock. No privileged host package installation.

PostgreSQL 18.0 Bookworm (supported major), Redis 8.2.2 Bookworm; Python 3.13.7 Bookworm simulator uses stdlib only. Workstation tools explicitly require kind 0.30.0, Terraform 1.16.5, kubectl compatible with Kubernetes 1.34.0. Kubernetes provider 2.38.0 locks in infra/.terraform.lock.hcl. Helm isn't needed: this small lab uses Kubernetes provider for explicit resources; no shared chart resource ownership. Docker 29.9.0 / Compose 5.6.0 were observed, not installed. kind node 1.34.0 is the release-default supported node for kind 0.30.0.

Prometheus 3.15.0, Grafana 13.2.3, Loki 3.7.8, Alloy 1.20.1: official release tags inspected on 2026-10-09. Alloy is the supported collector rather than end-of-life Promtail. All runtime images use version tags; immutable resolved digests captured in evidence. Pin tags plus lockfiles; updating versions requires tests and deliberate change.
