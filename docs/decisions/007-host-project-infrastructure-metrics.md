# Host and project infrastructure metrics
Use existing kubelet/cAdvisor and kube-state-metrics for namespace lab, plus a small native Linux collector with Pythonstdlib and the already available DockerCLI. No new privileged container, Docker socket mount in pods, host package installation or Docker daemon reconfiguration. Native process has existing user permissions and only read-only CLI operations; stats selection admits six Compose service names and the dedicated kind node. Internal kind bridge HTTPmetrics are trusted local traffic, not Internet/LAN endpoints; no authentication/security isolation claim beyond binding and existing network topology.

The transient project-only systemd unit restarts on failure; deployment starts it, teardown stops it. Discovered kind gateway is written to ignored runtime file and injected as Prometheus hostAlias. Checked-in manifests contain the current workstation bridge; deploy rediscovers it for clean starts. Collector source is versioned; runtime uses host Python and Docker versions recorded in evidence. No pip dependencies. `/proc`, statvfs and physical-interface/block-device counters measure whole host; not all usage can be attributed to the lab. Report database filesystem shares the host filesystem; disk space metric is not a per-project quota.

Docker stats are scoped to the project and distinguish Compose from kind; kind includes control plane and pods, so do not add kind and pod figures. CLI IO values are rounded; memory excludes inactive file cache on Linux. See https://docs.docker.com/reference/cli/docker/container/stats/ . Exporter counters/gauges and collection success follow https://prometheus.io/docs/instrumenting/writing_exporters/ . No claim of exhaustive kernel/device/daemon instrumentation: selected useful infrastructure metrics, with collection health visible and missing data unmasked.

Validate quantity conversion and scope exclusion through host-metrics.py --test; then query all provisioned Grafana panels and require host CPU/memory, DockerCPU/memory and KubernetesCPU/memory frames. Health gauge detects failed Dockercollection; up detects missing collector. Long-term stability and benchmark overhead have not been measured.
