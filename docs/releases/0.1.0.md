# 0.1.0 — Laravel reliability lab

The first public G1 release, approved by the user. This local portfolio lab does not represent production experience or establish a 30-day SLO.

- Laravel asynchronous processing with PostgreSQL/Redis, idempotency, durable acceptance, bounded retries, dispatch/worker recovery, and visible terminal failures.
- Docker Compose, a dedicated kind cluster, and Terraform-managed Kubernetes resources with bootstrap, validation, and data-preserving teardown commands.
- Prometheus/Grafana/Loki/Alloy, application and system/Docker/Kubernetes dashboards, SLI/SLO definitions, and an error-budget policy.
- Alertmanager/Mailpit authenticated local email: 15 notification routes tested for firing/resolved delivery and three real alert conditions triggered and recovered.
- A CI workflow definition, runbooks, an incident report, and capacity reports with reproducible local evidence.

Recorded local validation: 13 application tests with 47 assertions, 13 promtool fixtures including simulated long windows, Kubernetes smoke tests, 55 dashboard queries, seven healthy targets, Terraform validation, and 46 valid manifests. A total of 36 local messages were exported. In the latest short load tests, 40 requests/s passed and 50 requests/s showed latency saturation. Measurements apply only to the observed environment and duration; no capacity target was invented.

Limits: single-node cluster/database, ephemeral telemetry and inbox history, no distributed tracing, backup/HA validation, or external email delivery. Hosted CI had not run before this release was published; check GitHub for its subsequent result. See README.md, docs/validation.md, and docs/status.md.

Authorized publication: the personal public repository and tag `v0.1.0`. No merge or remote infrastructure deployment.
