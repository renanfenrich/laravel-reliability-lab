# Local email alerts

Recipient: `alerts@lab.test`; sender: `alertmanager@lab.test`. Mailpit captures SMTP messages locally with no external relay or forwarding. Open the authenticated UI using `make mail-up`; `LAB_BIND_ADDRESS` can select a trusted LAN address. Username `lab` and password `LAB_TOKEN` come from the local Secret, never a committed credential file. SMTP and metrics remain internal.

1. Check Prometheus `/api/v1/rules` and `/api/v1/alerts`: rule health and pending/firing states. Confirm windows, eligibility, and mode. `notification-fixture` tests delivery; `accelerated-demonstration` identifies the fault cohort. Both differ from the normal SLO population.
2. Check Prometheus `/api/v1/alertmanagers` for an active `alertmanager:9093` endpoint. Check Alertmanager `/api/v2/alerts` and `/api/v2/status` for receipt and configuration. Do not create silences to hide failed tests.
3. Check `up{job="alertmanager"}`, `up{job="mailpit"}`, `alertmanager_notifications_failed_total{integration="email"}`, and the logs of these deployments. The SMTP smarthost is `mailpit:1025`; TLS is disabled for this internal lab transport. Only `alerts@lab.test` is permitted. Do not substitute an external recipient under G1.
4. The inbox API `/api/v1/messages` returns 401 without authentication and lists messages with Basic authentication using `lab`/`LAB_TOKEN`. Export message JSON before rollouts. Do not clear the inbox to pass a test. Firing and resolved states produce separate messages; group wait is five seconds, group interval is ten seconds, and repeat interval is one hour.
5. `make alert-test` can stop the scheduler and host collector for several minutes. Its `finally` block restores both. After abrupt termination, restore the scheduler to one replica using the explicit project context and run `make host-metrics-up`. Terraform retains ownership of the baseline configuration; experimental scaling is temporary. Confirm `make smoke`, all targets UP, and alert resolution. A failed report remains failed after recovery. Its fault alert resolves when the deadline leaves the five-minute cohort, without editing records.

Limits: `SLOBurn*` is validated with simulated promtool windows and notification fixtures. The live test validates `LabDemoProcessingMiss`, `TelemetryUnavailable`, and `InfrastructureTelemetryUnavailable`, including actual delivery and resolution. It does not establish a 30-day SLO or external delivery. Mailpit/Alertmanager emptyDir storage is ephemeral; export results to `evidence/email-ID` for durable evidence.
